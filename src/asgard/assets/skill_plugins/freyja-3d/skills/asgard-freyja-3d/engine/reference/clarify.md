# 명세 확정 — 그리기 전에 확인한다

3D 요청은 거의 항상 불완전하다. "선반 브래킷 만들어줘" 에는 하중도, 벽 재질도, 나사 규격도, 만들 방법도 없다. 여기서 모델이 하는 흔한 실패는 **비어 있는 값을 그럴듯하게 채우고 확신에 찬 산출물을 내는 것**이다. 치수는 환각하기 가장 쉬운 값이면서 틀렸을 때 가장 비싼 값이다.

ProCAD(arXiv 2602.03045)는 코드 합성 전에 명세를 감사하고 **필요할 때만** 질문하는 에이전트를 두어, Chamfer 거리를 79.9% 줄이고 무효 산출률을 4.8%에서 0.9%로 떨어뜨렸다. 이 문서는 그 절차다.

## 규칙

1. **결과를 바꾸는 것만 묻는다.** 답이 무엇이든 같은 모델이 나온다면 묻지 않는다.
2. **한 번에 묻는다.** 질문은 최대 3개, 각각 기본값을 함께 제시한다. 왕복을 늘리는 질문은 확인이 아니라 지연이다.
3. **못 물으면 가정을 표면에 적는다.** 진행은 하되 `가정:` 으로 시작하는 줄에 값과 근거를 남기고, 그 값이 틀리면 무엇이 깨지는지 한 줄로 적는다.
4. **참조를 요구한다.** 실물·도면·스크린샷·기존 부품이 있으면 말로 된 설명 열 줄보다 정확하다.

## 레인별 필수 항목

### cad — 없으면 물어야 하는 것

| 항목 | 왜 결과를 바꾸는가 | 기본값(명시 후 진행 가능) |
|---|---|---|
| 단위 | mm/inch 혼동은 1000배 오차다 | mm |
| 전체 크기 또는 기준 치수 | 나머지 모든 치수의 앵커 | 참조물에서 유도, 불가하면 질문 |
| 제조 공정 | 최소 살두께·오버행·공차·언더컷 가능 여부가 전부 다르다 | FDM(가장 제약이 강한 쪽) |
| 상대물 인터페이스 | 나사 규격, 결합 부품 치수, 볼트 원주 | 질문 — 추정 금지 |
| 하중·용도 | 두께·리브·재료 선택 | "가벼운 실내 용도"로 명시 후 진행 |
| 끼워맞춤 간극 | 조립되는가 안 되는가를 가른다 | 공정별 기본값(dfm.md) |

**절대 추정하지 않는다**: 상대물과 맞물리는 치수(나사 피치, 베어링 외경, 커넥터 핀 피치, 기존 구멍 위치). 이건 물어보거나, 규격 부품 데이터시트를 확인하거나, 사용자가 실측해야 한다.

### realtime — 없으면 물어야 하는 것

| 항목 | 왜 | 기본값 |
|---|---|---|
| 대상 기기 | 예산 전체가 여기서 나온다 | 모바일 중급기 (budgets.md) |
| 프레임워크 | R3F/Vue/Svelte/바닐라에 따라 코드가 다르다 | 프로젝트 package.json 을 먼저 본다 |
| 자산 출처 | 만들 것인가 받을 것인가 | 있으면 그것, 없으면 프로시저럴 |
| 인터랙션 범위 | 보기만/조작/구성기 | 질문 — 작업량이 배로 갈린다 |
| WebGPU 여부 | TSL 포팅 필요 여부 | WebGL2 기본 + WebGPU 자동 폴백 |

### motion — 없으면 물어야 하는 것

- 트리거(스크롤/호버/자동/데이터)와 되돌아갈 수 있는지.
- 지속 시간과 "이 모션이 사용자에게 알려야 하는 것" — 알릴 것이 없으면 그 모션은 빼는 것이 맞다.
- 저감 모션에서 무엇을 남길지. (전부 제거가 답인 경우는 드물다. 보통 즉시 최종 상태로 전환.)

## 모순 감지

명세가 비어 있는 것보다 서로 어긋나는 것이 더 위험하다. 다음은 그리기 전에 반드시 되짚는다.

- 치수 합이 전체 크기를 넘는다(벽 두께 × 2 > 외경).
- 공정과 형상이 충돌한다(CNC 인데 내부 밀폐 공간, FDM 인데 0.3mm 벽, 사출인데 언더컷).
- 공차와 공정이 충돌한다(FDM 에 ±0.05mm 요구).
- 성능 예산과 요구 품질이 충돌한다(모바일 60fps + 100만 삼각형 + 4K 텍스처 4장).
- 참조 이미지와 말이 다르다. 이때는 참조가 이긴다고 가정하지 말고 어느 쪽인지 묻는다.

모순을 발견하면 **한 문장으로 지적하고 선택지 두 개를 제시**한 뒤, 답이 없으면 더 보수적인 쪽으로 진행하고 그 사실을 적는다.

## 산출

이 단계의 결과물은 짧은 명세 블록이다. 코드 상단 주석이나 `PARAMS` 딕셔너리로 그대로 옮겨 적어, 모델과 명세가 한 파일에서 붙어 있게 한다.

```
용도: 벽걸이 선반 브래킷, 실내, 정하중 5kg 이하
공정: FDM PLA, 0.2mm 층, 서포트 없이
치수: 40(W) × 30(D) × 50(H) mm, 판 두께 4mm
인터페이스: M5 관통 2개, 벽 앵커 피치 32mm (사용자 실측값)
간극: 볼트 구멍 지름 +0.6mm
가정: 하중 방향은 아래쪽 수직 — 옆방향 충격은 고려하지 않음
```
