# 제조 규칙 (DFM)

수치 원본은 `engine/data/processes.json` 이다. `mesh_audit.mjs` 가 자동 판정하는 것은 그중 살두께(minWall·recommendedWall)·오버행(overhangDeg)·조형 공간(buildVolume)이고, 나머지(구멍 지름, 간극, 브리지, 구배, 리브, 내부 반경)는 설계 시 이 문서와 함께 **사람이 대조하는 기준값**이다. 여기서는 **왜 그 숫자인지**와 **자동 검사가 못 잡는 것**을 다룬다.

모든 값은 보수적 기본선이다. **벤더 데이터시트와 실제 장비 설정이 항상 우선한다.** 값을 낮추려면 근거를 함께 적는다.

## 공정 요약

| 공정 | 최소 살두께 | 오버행 | 끼워맞춤 간극 | 일반 공차 |
|---|---|---|---|---|
| FDM | 0.8mm (권장 1.2) | 45° | 0.3mm (움직이면 0.5) | ±0.5mm 또는 ±0.5% |
| SLA/DLP | 0.5mm (물리 한계 0.2) | 45°, 서포트 전제 | 0.2mm | ±0.15mm |
| SLS/MJF | 0.7mm | 제약 없음(분말 지지) | 0.4~0.5mm | ±0.3mm |
| CNC 밀링 | 0.8mm(금속) / 1.5mm(플라스틱) | 해당 없음 | 설계 공차대로 | ISO 2768-m |
| 사출 성형 | 1.0~4.0mm, **균일하게** | 해당 없음 | 금형 설계 사항 | 재료 수축률에 따름 |

## 자동 검사가 잡는 것

`mesh_audit.mjs` 는 메시에서 다음을 직접 측정한다.

- **수밀·매니폴드**: 열린 에지, 비매니폴드 에지, 감김 불일치. 슬라이서가 거부하는 형상을 미리 잡는다.
- **살두께**: 면 중심에서 안쪽으로 광선을 쏘아 반대면까지의 거리를 표본화한다. 최소·1퍼센타일·중앙값과 위치 좌표를 낸다.
- **오버행**: 하향면의 수평면 기준 기울기. **빌드 플레이트에 붙은 바닥면은 제외**한다 — 이 예외가 없으면 평평한 바닥을 가진 모든 부품이 거짓 실패로 표시된다(흔한 오탐).
- **셸 분리**: 조립체 메시에서 부품이 여러 개면 살두께 광선이 이웃 부품에 닿는다. 셸 수를 보고하고 `--shell N` 으로 부품마다 따로 재게 한다.
- **조형 공간**: 회전을 허용한 상태로 장비 크기와 비교한다.

## 자동 검사가 못 잡는 것 — 사람이 봐야 한다

- **구멍 지름과 공차.** 메시에서 원기둥 지름을 신뢰성 있게 역산할 수 없다. CAD 파라미터에서 확인한다.
- **하중·강도.** 벽이 두꺼운 것과 튼튼한 것은 다르다. 하중 방향과 적층 방향의 관계, 리브·거싯 배치는 판단의 영역이다.
- **언더컷·공구 접근성(CNC).** 절삭 공구가 닿는지는 형상·클램핑·공구 길이의 문제다.
- **구배(사출).** 이형 방향이 정해져야 계산할 수 있다.
- **표면 품질·심미.** 서포트 자국이 어디 남는지, 층결이 어느 면에 보이는지.

## 공정별 설계 지침

### FDM
- 45° 미만 하향면은 서포트를 요구한다. **챔퍼나 물방울 단면으로 치환하면 서포트 자체를 없앨 수 있다** — 이것이 오버행 경고에 대한 최선의 대응이다.
- Z 방향(층간) 인장 강도가 XY 보다 현저히 낮다. 하중 방향을 먼저 정하고 인쇄 방향을 그에 맞춘다.
- 수평 관통 구멍은 상단이 처진다. 물방울(teardrop)이나 육각 단면이 안전하다.
- 첫 층 접지 면적이 작으면 떨어진다. 브림이나 접지면 확장을 설계에 반영한다.

### SLA/DLP
- 밀폐 중공은 레진이 갇혀 흡착컵이 된다. 지름 3~4mm 배출홀을 **두 곳 이상**.
- 서포트 자국은 접촉면에 남는다. 노출면을 위로 향하게 방향을 잡는다.
- 얇고 넓은 판은 후경화에서 휜다. 리브를 넣거나 두께를 올린다.

### SLS/MJF
- 오버행 제약이 없어 복잡한 형상에 유리하다. 대신 **미소결 분말 배출홀(≥4mm)** 이 필수다.
- 조립체를 한 번에 인쇄할 수 있다. 움직이는 부품 사이는 0.5mm 이상.
- 표면이 거칠다(Ra 10~20µm). 씰링면·미관면은 후처리를 전제로 설계한다.

### CNC
- **내부 코너에 직각은 없다.** 공구 반경이 곧 코너 반경이다. 최소 R1.0mm, 포켓 깊이의 1/3 이상을 준다.
- 최소 살두께 기준 0.8mm 는 금속 일반값이다. 알루미늄은 0.5mm 까지 내려갈 수 있지만 채터·변형 위험을 감수하는 값이라, 내리려면 가공처와 먼저 합의한다.
- 포켓 깊이:폭 비는 표준 공구로 3:1, 연장 공구로 최대 6:1(비용 상승).
- 비지지 벽의 높이:두께 비는 4:1 이하. 넘으면 채터로 치수가 흔들린다.
- 언더컷과 내부 밀폐 형상은 만들 수 없다 — 분할 가공 후 결합이거나 공정 변경이다.
- 도면에 기준면(datum)과 클램핑 면을 명시한다.

### 판금
- 부품은 **단일 두께**다. 두께가 다른 영역이 필요하면 별 부품으로 나눠 결합한다.
- 최소 굽힘 반경은 재료 두께 t 이상(연질 알루미늄 t, 강 1.0~1.5t).
- 구멍은 모서리에서 2t, 굽힘선에서 3t + 반경 이상 떨어뜨린다.
- K-factor 는 공정·재료마다 다르다. 전개도는 **제조사 값으로 재계산**해야 한다 — 여기서 나온 전개 치수를 그대로 발주하지 않는다.

### 사출 성형
- 두께 균일성이 최우선이다. 두꺼운 부위는 수축과 싱크마크를 만든다.
- 이형 방향의 모든 면에 1° 이상 구배(텍스처면은 3° 이상).
- 리브 두께는 인접 벽의 0.6배 이하, 높이는 두께의 3배 이하.
- 언더컷은 슬라이드 코어를 요구한다 — 금형비가 오른다. 설계 단계에서 피하는 것이 가장 싸다.

## 공차를 다루는 법

- 공차는 **기능에서 나온다.** 맞물리는 면에만 좁은 공차를 주고 나머지는 일반 공차로 둔다. 전면 ±0.05mm 는 비용만 올린다.
- 시제품은 **테스트 조각부터**. 끼워맞춤 간극은 장비·재료·설정마다 달라서 표의 값은 시작점일 뿐이다. 0.2/0.3/0.4mm 세 개를 한 번에 뽑아 확인하는 것이 가장 빠르다.

### 끼워맞춤 등급 (FDM, 0.4mm 노즐·0.2mm 레이어 보정 기준)

| 등급 | 지름 간극 | 용도 |
|---|---|---|
| 압입(press) | −0.1 ~ −0.2mm (구멍을 작게) | 고정 축·인서트 |
| 밀착(slip) | 0.15 ~ 0.25mm | 손으로 눌러 끼움, 유격 없음 |
| 활동(running) | 0.25 ~ 0.35mm | 자유롭게 움직임 |
| 여유(loose) | 0.4 ~ 0.6mm | 쉬운 조립·분해 |

- FDM 구멍은 설계보다 **0.1–0.2mm 작게 출력된다** — 모델에서 보상한다. 어림 대안: 간극을 압출 폭 배수로(1×≈0.4mm 활동, 2× 여유).
- SLA 는 공차가 한 급 좋다(±0.1mm 급) — 등급을 한 단계 좁혀도 된다. 어느 쪽이든 공차 빗(tolerance comb) 조각을 먼저 뽑는 습관이 가장 싸다.

### 스택업 계산 — 직렬로 맞물리는 치수는 오차도 직렬로 쌓인다

두 가지 계산법이 있고, 어느 쪽을 썼는지 명세에 적는다.

- **Worst-case**: `T = Σ|tᵢ|`. 모든 부품이 동시에 극단 치수일 때도 조립된다는 보증. 치수 사슬이 짧거나(≤4개) 실패 비용이 클 때(안전·단품·수리 불가) 쓴다.
- **RSS(제곱합 제곱근)**: `T = √(Σtᵢ²)`. 공정이 통계적으로 관리될 때(양산) 현실적인 추정. 사슬이 길수록 worst-case 대비 여유가 커진다. 단품·3D 프린트 시제품에는 근거가 약하다 — 표본이 1개라 통계가 없다.

예: 부품 3개 각 ±0.2mm 직렬 → worst-case ±0.6mm, RSS ±0.35mm. FDM 단품이면 worst-case 를 쓰고, 목표 간극은 스택업보다 커야 한다: `간극 ≥ T + 최소 작동 간극`.

**cad_build 로 검증한다** — 공차를 파라미터로 올려 두 극단을 빌드하면 스택업이 커널 검사가 된다:

```python
TOL = 0.2                       # 공정 공차(±)
STACK = 3 * TOL                 # worst-case 스택업
CLEAR = STACK + 0.1             # 목표 간극 = 스택업 + 작동 여유
# 최악 조건 형상으로 조립을 한 번 더 빌드한다 — pin 은 최대재료조건(+TOL), hole 은 -TOL.
```

`--clearance` 를 `CLEAR` 로 넘겨 pair 검사가 그 기준으로 판정하게 하라. 명목 치수로만 빌드해 통과한 조립은 최악 조건에서 조립되지 않을 수 있다.
