# 뷰어 — 로컬 리뷰 서버

사람이 눈으로 돌려보는 창. STEP·GLB·STL·OBJ·3MF 를 로컬 브라우저에서 열고, DXF·G-code·URDF·SRDF·SDF 는 원문으로 띄운다.

**뷰어는 편의이지 검증이 아니다.** 검증의 본체는 `inspect` 의 측정값과 `snapshot` 의 렌더 증거다. 뷰어가 안 떠도 배달은 진행된다 — 못 띄웠다고 적으면 된다. 반대로, 뷰어 링크를 돌려줬다는 사실도 검증이 아니다.

## 기동

```bash
node engine/scripts/view.mjs --dir <산출물 디렉터리> --port 4178
```

`--dir` 없이 띄우면 현재 작업 디렉터리를 연다. 다른 디렉터리는 URL 질의로 바꾼다:

```text
http://127.0.0.1:4178/?dir=<절대 디렉터리>&file=<dir 기준 상대 경로>
```

`file=` 없이 열면 그 디렉터리의 카탈로그가 나온다.

## 서버가 그린다

브라우저로 3D 라이브러리를 내려보내지 않는다. 렌더는 `engine/scripts/core/raster.mjs` — 스냅샷이 쓰는 바로 그 오프라인 래스터라이저 — 가 서버에서 돌리고, 브라우저는 `<img>` 를 바꿔 다는 일만 한다.

그래서:

- WebGL 이 없거나 막힌 환경에서도 뜬다.
- 내려보내는 페이지가 한 파일이고 외부 자산이 없다.
- 각도를 바꿀 때마다 왕복이 한 번 생긴다. 로컬호스트에서 수십 밀리초라 리뷰용으로는 문제없지만, **60fps 로 굴리는 뷰어가 아니다.** 부드러운 조작이 과업의 일부라면 실제 실시간 런타임을 띄우고 `lane-realtime.md` 로 판정한다.

조작은 셋이다: 회전(방위각), 고도, 단면 축. 단면은 삼각형을 쪼개지 않고 평면 바깥을 통째로 버리므로 **절단면이 톱니로 나온다** — 내부 배치를 보는 용도지 절단면 형상을 재는 용도가 아니다. 그 치수는 `inspect measure` 로 잰다.

## STEP 을 열 때

STEP 에는 삼각망이 없다. 뷰어는 옆의 위상 산출물(`.<이름>.step.glb`)에서 메시를 읽으므로, `cad.py step` 으로 생성한 STEP 이라야 열린다. 산출물이 없으면 404 와 사유가 나온다 — 빈 화면을 보여주지 않는다.

## 준비 상태 확인

```bash
curl -s http://127.0.0.1:4178/__cad/server
```

`{"schemaVersion":1,"app":"asgard-freyja-3d-view",…,"ready":true}` 가 오면 준비된 것이다. 미리보기 도구에 URL 을 넘기기 전에 이걸로 200 을 확인한다.

## 링크를 돌려주기 전에

- **`<dir>/<file>` 이 실제로 있는지 확인한다.** 없는 링크를 돌려주지 않는다.
- 생성물을 가리킨다(`.step`), 생성기를 가리키지 않는다(`.py`).
- 파일마다 URL 하나. 디렉터리당 서버는 한 번만 띄우고 `file=` 만 바꾼다.
- **사용자가 요청하지 않으면 돌고 있는 서버를 끄지 않는다.** 다른 세션이 쓰고 있을 수 있다.

## 안 될 때

샌드박스에서 로컬 바인딩이 `EPERM`·`EACCES` 로 막히는 것은 정상적으로 있는 일이다. 포트가 점유돼 있으면 `--port` 로 다른 번호를 준다.

**띄우지 못했으면 그렇게 보고하고, CLI 사실·측정·스냅샷으로 검증을 마친다.** 뷰어 링크가 없다고 검증이 없는 것이 아니다.

## 경계

- 서버는 `--dir`(또는 `?dir=`) 아래만 연다. 그 밖을 가리키는 경로는 403 이다.
- 원문 표시는 512KiB 에서 자르고, 잘렸다는 사실을 표시한다.
- 재질·텍스처·IBL·톤매핑을 그리지 않는다. **룩 판정에 쓰지 않는다**(`look-floor.md`).
- 로봇 파일은 원문으로 열린다. IK·경로 계획을 대화적으로 보려면 MoveIt2 환경이 따로 필요하고, 그것은 이 엔진의 범위 밖이다 — 필요하면 설치 비용을 먼저 말한다.
