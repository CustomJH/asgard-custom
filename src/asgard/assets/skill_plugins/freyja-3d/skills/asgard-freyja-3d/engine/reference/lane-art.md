# art 레인 — 히어로 자산을 아티스트처럼

CAD 커널의 산출물과 게임 아트의 거리는 "품질"이 아니라 **공정**의 차이다. 현업 히어로 무기 한 자루는
아래 아홉 단계를 지나며, 각 단계에 수치 기준이 있다(출처는 research.md 의 art 절). 이 레인은 그 공정을
이 엔진의 도구·승급 경로·수렵 경로에 사상한다.

## 아홉 단계 — 각 단계의 지배 규칙

| 단계 | 지배 규칙 | Freyja 에서 |
|---|---|---|
| 1 레퍼런스 | 정사영 4면 + 마모 맥락 사진. 컨셉 위에 오버레이해 실루엣을 검증한다 | clarify 게이트에서 레퍼런스·용도 확인 |
| 2 블록아웃 | **실루엣이 디테일보다 먼저다.** 실루엣이 컨셉과 일치할 때까지 디테일 금지 | 파라메트릭 블록아웃 + `shoot` 정사영으로 실루엣 검증 |
| 3 하이폴리 | **모든 모서리에 베벨.** 폭 0 에지는 베이크에 안 잡힌다 — 챔퍼 폭이 재질감을 판다 | CAD 챔퍼/필렛, 혹은 Blender 승급 |
| 4 로우폴리 | AAA 히어로 무기 LOD0 = **15–40k tri**. 카메라가 머무는 곳에 밀도를 몰아준다 | `cad.py step --deflection/--angular` 로 예산 제어, `scene_audit` 판정 |
| 5 UV | 텍셀 밀도 통일: 1인칭 **10.24 px/cm**, 3인칭 5.12. 하드 에지에는 반드시 UV 심 | 승급(Blender smart_project) — 아티스트급 심은 미해결 연구 영역 |
| 6 베이크 | mesh maps: 노멀·AO·**커버처**·두께. AO 표준 64레이/180°. 2× 해상도, MikkTSpace | `mesh_polish --bake` — 정점 AO(코사인 가중 반구)·부호 이면각 커버처 → COLOR_0 |
| 7 텍스처 | **커버처→엣지 웨어, AO→그라임**, ID→존 분리. 제너레이터 80% + 손 20%(이야기) | 베이크 마스크 + 노이즈 셰이딩(아래), 풀 텍스처는 승급/수렵 |
| 8 룩뎁 | 3점 조명 + HDRI + 톤맵. 턴테이블 8–12초 | 실제 DCC/엔진의 뷰티 렌더 + `shoot` 형상 시트. `shoot`는 PBR 룩을 그리지 않는다 |
| 9 엔진 통합 | LOD 3–4단(단마다 −50%), Nanite 는 정적 메시만 면제. ORM 패킹 | `scene_audit` 예산, gltf-transform simplify |

## 모델링 문법 — 셰이딩이 판정한다

- **워크플로는 셋이고 선택 기준이 있다.** 유니크 히어로 = 하이폴리 SubD + 베이크(다수 스튜디오 표준). 대형 하드서피스·모듈러 = 미드폴리 + 면적 가중 노멀(FWN — 실챔퍼 + 큰 면에 수직으로 구부린 정점 노멀, 베이크 없음; 정점 수가 하드엣지 분할보다 적고 노멀맵 압축이 좋다). 오픈월드 환경 = 트림 시트 + 45° 노멀 베벨 + 메시 데칼(Ultimate Trim, GDC 2015). 셋을 섞는 것이 현업 기본이다: 실루엣 베벨은 베이크, 고주파 디테일은 텍스처.
- **베벨 폭은 피처 크기에 비례한다.** 자산 전체 균일 폭은 초보 티다 — 나사머리가 패널만큼 두꺼운 베벨을 가지면 크기가 무너진다. 게임 해상도 베벨은 2–3 세그먼트면 충분하고, 노출·마모 부위만 벼린다.
- **하드 에지 ⇔ UV 심 1:1.** "모든 하드 에지는 UV 심이어야 한다. 모든 UV 심이 하드 에지일 필요는 없다"(Polycount 정칙). 근거: 하드 에지는 정점 노멀을 쪼개고, UV 를 안 쪼개면 양쪽 값이 이웃 텍셀에 겹쳐 베이크 심이 생긴다. 90° 외곽 코너는 표면 방향이 270° 도는데 탄젠트 노멀맵 범위는 180° 다 — 하드 에지 + UV 분할 + 패딩이 필수인 기하적 이유. 안전 공식: **스무딩 그룹 하나 = UV 섬 하나.**
- **불리언은 정리까지가 공정이다.** 교차부 ngon 이 셰이딩을 깨면: 정점 병합 → 엣지 흐름 재배선 → 필요한 곳만 서포트 루프. 내부 면·비다양체 에지를 지운다. 판정: "셰이딩이 멀쩡하면 베이크도 멀쩡하다." ngon 은 정적 메시의 평면에서만 허용, 변형(스킨) 메시는 쿼드 루프.
- **베이크·내보내기 전에 직접 삼각화한다.** 베이커와 엔진의 자동 삼각화가 다르면 셰이딩이 어긋난다(Adobe 공식 권고). 케이지는 평균 노멀로 — 하드엣지 경계에서 명시 노멀 케이지는 틈을 만든다.
- **패딩(UV 거터):** 노멀맵 최소 8px, 밉 4단 유지면 16px, 셸 간격은 패딩의 2배.

## 텍스처 스택 규율 — 아래가 오래된 역사다

레이어 순서는 물리적 지층이다: **바탕 재질 → 매크로 변주(색·러프니스) → 마모·긁힘(아래층 드러냄) → 먼지·그라임(오목 축적) → 이야기 디테일(흘림·데칼·지문)**. 위로 갈수록 최근 사건이다.

- 제너레이터는 70–80% 까지만 — 남는 20–30% 는 손이다. 마스크를 만들었으면 **수동으로 깨서** 제네릭 티를 지운다(현업 정칙: "순수주의자가 되지 마라").
- 마모는 정당화가 필요하다: 이 물건이 겪은 일이 텍스처에서 읽혀야 한다. 손이 닿는 곳, 부딪히는 곳에만. 완전 대칭·미러 마모는 CG 티다.
- 재질을 파는 것은 러프니스 변주다 — 균일 러프니스가 "플라스틱" 티의 절반이다. 색 균형 어림: 주 75% / 부 20% / 디테일 5%.
- 높이 채널은 HDR 이다 — 16비트(EXR)로 내보내거나 노멀로 구운 뒤 내보낸다.

## PBR 보정 범위 — 이 밖이면 조명이 망가진다

- 알베도: 30–240 sRGB (석탄보다 어둡게, 새 눈보다 밝게 만들지 않는다)
- 비금속 F0 ≈ 0.04, 금속 반사율 70–100% · baseColor 가 곧 반사색
- 기계 가공 금속: metallic 0.9–1.0 / roughness 0.2–0.5, 폴리머: metallic 0 / roughness 0.6–0.8

## 마모는 이야기다 — 마스크 산수

Substance Edge Wear 계열 노드의 로직은 전부 이 산수다. `mesh_polish --bake` 의 COLOR_0 이 원료다:

```
wear   = smoothstep(t1, t2, edge(G)) × grunge_noise      # 볼록 → 칠 벗겨진 생금속
grime  = (1 - AO(R)) × cavity(B) 가중 × 어두운 틴트        # 오목·가림 → 기름때
story  = 손이 닿는 곳(그립 상단), 칼집이 스치는 곳(날 하단 측면)에 수동 가중
```

마모가 물리적으로 앉을 수 없는 곳(오목면의 엣지 웨어, 돌출부의 그라임)에 마스크가 생기면
베이크나 부호가 뒤집힌 것이다 — 판정 기준을 의심하기 전에 베이크를 다시 본다.

## 노이즈 레이어링 — 재질 미시 구조

- 브러시드 금속: 이방성 노이즈(연마 방향으로 좌표를 늘린 fbm)를 roughness 에
- 가죽: 등방 fbm 그레인을 알베도·노멀 섭동에
- 트라이플래너 투영이면 UV 없이도 위 전부가 된다(월드 좌표 3축 투영, 법선 가중 블렌드)

## 예산의 철학

밀도·해상도는 **스크린 타임에 비례 배분**한다. 히어로 = 유니크 2–4K 텍스처와 상급 인력,
소품 = 트림 시트·타일러블, 배경 = 공유 아틀라스. 전부에게 히어로 대접을 하는 것은
아무에게도 안 하는 것과 같다. 트림 시트는 가로 타일링으로 사실상 무한 텍셀 밀도를 얻는
역-워크플로(모델 → 기존 시트에 UV)다.

- 승급(escalation.md): 스컬프트 하이폴리, 애니메이션급 리토포, 아티스트 UV, 텍스처 페인팅, 노멀맵 베이크
- 수렵(lane-asset.md): 트림 시트·스캔 라이브러리·킷배시 — 보조 표면은 만들지 말고 가져온다
